# 다이어리 서비스 요구사항 정의서

개인·회사 일정과 할 일을 하나의 캘린더에서 관리하는 다이어리 서비스.
PC와 모바일 모두 사용 가능한 반응형 웹.

---

## 1. 기술 스택

| 구분 | 선택 |
|---|---|
| 프레임워크 | React + TypeScript |
| 스타일 | TailwindCSS |

## 2. 데이터 전략

별도 백엔드 서버나 Mock API(MSW)는 만들지 않는다.
저장소 어댑터 레이어를 두고, 구현만 교체하는 2단계 방식으로 진행한다.

**1단계 — localStorage**
- 가입·설정·비용 없음
- 단일 기기 내에서 전체 기능 완성
- 기기 간 동기화 불가

**2단계 — Firebase Firestore**
- 어댑터 파일 내부만 교체, 훅·컴포넌트 수정 없음
- 브라우저에서 직접 읽고 쓰므로 서버 코드 불필요
- 스키마가 없어 모델 변경 시 마이그레이션 부담이 적음
- PC ↔ 모바일 실시간 동기화

> 어댑터 함수는 1단계부터 전부 `async`로 작성한다. 동기로 만들면 2단계 전환 시 호출부를 모두 수정해야 한다.

**저장 키 (1단계)**

| 키 | 값 |
|---|---|
| `diary:tasks` | Task[] |
| `diary:groups` | Group[] (회사·개인 2건, 최초 실행 시 시드) |
| `diary:version` | 마이그레이션 대비 버전 |

## 3. 데이터 모델

일정과 할 일을 구분하지 않고 **Task 하나로 통합**한다.
시간(`time`)은 선택값이며, 값이 없으면 종일 항목으로 취급한다.

```ts
type Task = {
  id: string;
  title: string;
  groupId: string;          // 'g_work' | 'g_personal'
  date: string;             // YYYY-MM-DD
  time?: string;            // HH:mm — 없으면 종일
  done: boolean;
  order: number;            // 그룹 내 수동 정렬 순서
  recurrence?: {
    freq: 'daily' | 'weekly' | 'monthly';
    until?: string;
    exdates: string[];      // 반복 예외 날짜
  };
  reminder?: { enabled: boolean; offsetMin: number };
  memo?: string;
};

type Group = {
  id: string;
  name: string;             // 고정값, 변경 불가
  color: string;            // 변경 가능
};
```

**Group 제약**
- 회사 / 개인 2개로 고정
- 추가·삭제·이름 변경 불가
- **색상만 변경 가능**
- 두 그룹이 동일한 색을 선택할 수 없음

## 4. 기능 범위 (MVP)

| 기능 | 내용 |
|---|---|
| 월간 캘린더 | 이전·다음 달 이동, 오늘로 이동, 날짜 선택 |
| 캘린더 셀 | 항목 바(그룹 색상) 최대 3건 + `+N`, 완료 항목은 회색·취소선 |
| 할 일 CRUD | 생성·수정·삭제, 완료 체크 토글 |
| 시간 선택 | `시간 설정` 토글 on/off, off면 종일 |
| 반복 | 매일·매주·매월, 종료일 지정. 수정·삭제 시 범위 선택 |
| 드래그 | 그룹 내 순서 변경 + 그룹 간 이동(드롭 시 groupId 변경) |
| 그룹 필터 | 상단 칩으로 회사·개인 토글, 캘린더와 리스트에 동시 반영 |
| 알림 | 브라우저 Notification API 기반 |
| 그룹 색상 설정 | 프리셋 팔레트에서 선택 |

**반복 일정 처리**
- 저장소에는 원본 1건 + 반복 규칙만 보관
- 화면 표시용 전개는 클라이언트 `expandRecurrence`에서 수행
- 수정·삭제 시 범위 선택: `이 항목만` / `이후 전체` / `전체`

**알림 제약**
- 브라우저 탭이 열려 있을 때만 동작한다. 백그라운드 알림은 Service Worker + 푸시 서버가 필요하므로 MVP 범위 밖이다.
- 시간이 있는 항목은 해당 시각 기준, 종일 항목은 설정의 기본 알림 시각 기준으로 발송한다.

## 5. 화면 설계

### 5.1 PC (≥1024px)

```
┌───────────────────────────────────────────────────┐
│ 다이어리 │ ‹ 2026.09 › [오늘] │  ●회사 ●개인  ⚙   │
├─────────────────────────────┬─────────────────────┤
│ 월간 캘린더 (7×5~6 그리드)    │ 9월 21일 월요일      │
│  · 날짜 / 요일 헤더           │ 4개 중 1개 완료      │
│  · 항목 바 + "+N"            │                     │
│  · 오늘: 연보라 원            │ 회사 2              │
│  · 선택: 연보라 테두리        │  ┃ ☐ 분기 마감 정리  │
│                             │  ┃ ☐ 09:00 주간회의 │
│                             │                     │
│                             │ 개인 2              │
│                             │  ┃ ☐ 14:00 치과    │
│                             │  ┃ ☑ 택배 발송      │
│                             │                     │
│                             │ [+ 할 일 추가]       │
└─────────────────────────────┴─────────────────────┘
```
- 우측 패널 고정 폭 372px

### 5.2 모바일 (<1024px)

```
┌─────────────────────┐
│ ‹ 2026.09 › [오늘] ⚙ │
│ ●회사  ●개인         │
├─────────────────────┤
│ 월간 캘린더           │
│ (셀 높이 62px,        │
│  항목은 색상 바로 축약) │
├─────────────────────┤ ← 시트 핸들
│ 9월 21일 월요일        │
│ 회사 2                │
│  ┃ ☐ 분기 마감 정리    │
│ 개인 2                │
│  ┃ ☐ 14:00 치과      │
└─────────────────────┘
                  [ + ]  ← FAB
```
- 하단 시트 3단계 스냅: peek / half / full
- 시트를 위로 올리면 캘린더가 주간 뷰로 축소

### 5.3 리스트 표시 규칙

- **탭 없음.** 일정·할 일 구분 없이 모두 할 일로 통합
- **그룹 라벨 상시 노출** (회사 / 개인), 라벨 왼쪽에 그룹 색상 점
- 그룹 사이는 구분선 없이 여백 24px로만 분리
- 그룹 내 정렬: 시간 없는 항목 → 시간 있는 항목(오름차순)
- 카테고리는 태그 대신 **항목 좌측 3px 컬러 바**로 표시
- 완료 항목은 자리 이동 없이 제자리에서 회색 + 취소선
- 빈 그룹도 라벨을 유지하고 빈 상태 문구 노출
- 필터를 끄면 해당 그룹 블록 전체가 숨김

### 5.4 화면 목록

1. 메인 — 캘린더 + 패널
2. 할 일 등록·수정 — PC 모달 / 모바일 풀스크린
3. 반복 수정 범위 선택 다이얼로그
4. 삭제 확인 다이얼로그
5. 설정 — 그룹 색상, 알림 권한, 기본 알림 시각

### 5.5 등록 폼 필드

제목 · 날짜 · 그룹 · `시간 설정` 토글 · 반복 · 알림 · 메모

## 6. 디자인 토큰

| 용도 | 값 |
|---|---|
| 회사 | `#C0E8DD` |
| 개인 | `#A3C6EB` |
| 강조 (오늘·선택) | `#D8B4D6` |
| 배경 | `#FFFFFF` / `#FAFAFB` |
| 경계 | `#EDEEF1` / `#E0E2E7` |
| 본문 텍스트 | `#2B2D31` |
| 보조 텍스트 | `#5C6068` |
| 흐린 텍스트 | `#9CA1A9` |
| 서체 | IBM Plex Sans KR (300 / 400 / 500 / 600) |

**색상 사용 원칙**
- 파스텔 색은 대비가 낮으므로 **글자색으로 쓰지 않는다**
- 컬러는 항목 바 배경, 좌측 3px 바, 그룹 점, 필터 칩 점에만 사용
- `#D8B4D6`는 오늘·선택 표시 전용으로 그룹 색과 역할을 분리

**접근성**
- 색상만으로 그룹을 구분하지 않는다. 그룹 라벨 텍스트를 항상 노출하고, 항목 `aria-label`과 상세 화면에 그룹명을 포함한다
- 키보드 포커스 링 표시, `prefers-reduced-motion` 대응

## 9. 상태 관리

**TanStack Query — 서버(저장소) 상태**

| queryKey | 내용 |
|---|---|
| `['tasks', { from, to }]` | 기간 내 항목 조회 |
| `['groups']` | 그룹 2건 |

- 체크 토글·순서 변경은 `onMutate` 낙관적 업데이트 + 실패 시 롤백
- 월 이동 시 `placeholderData: keepPreviousData`로 깜빡임 방지

**Zustand — UI 상태**

`selectedDate` · `currentMonth` · `groupFilters` · `sheetSnap` · 모달 open 상태

## 10. 미결 사항
